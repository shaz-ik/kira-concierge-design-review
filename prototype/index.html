Demo controls

Autopilot staffFor solo walkthroughs of the guest tablet: the room’s requests move forward every few seconds as if staff were working them.
Simulate failuresThe menu fails to load once, and the first order send fails, so you can see the retry screens. Retrying never creates a duplicate order.
Reset the hotelRestores the starting orders, requests, menu and rooms on every open app.
Try this (about 2 minutes)
  1. On the tablet, tap In-room dining, add two burgers and a Coke, then Confirm & send.
  2. In Kitchen, open order #4821 → Start preparing → Mark ready.
  3. In Waiter, Claim delivery → Mark delivered. The tablet’s tracker follows every step.
  4. Ask for a 5 PM late checkout. In Front desk, approve it (the guest confirms the AED 90 fee) or deny it with a reason.
  5. In Admin → Menu, pause the burger. It disappears from the tablet menu at once.

This prototype runs entirely in your browser. There’s no backend. The shared hotel lives in this browser’s local storage, so apps open in other tabs of the same browser stay in sync, but other people’s browsers don’t. Voice is simulated: tap a phrase or type, or use the microphone where the browser supports it.

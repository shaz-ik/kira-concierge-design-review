The Lantern — avatar states

Idle

Slow breathing pulse

Wake

Quick brighten + pop

Listening

Tight pulse + sound ripple

Thinking

Slow colour drift, never frozen

Speaking

Rhythmic pulse, no lip-sync needed

Form: an abstracted hanging lantern — hanger ring, brass cap and collars, a faceted glass body with two ribs, and a single flame-shaped light — not a face or a generic glowing orb. It ties the one AI-native element in the room to the hospitality material language around it. These are the static hero frames per state; the rigged Rive/Lottie animation is built from the same linework per the avatar design brief (design/avatar/avatar-brief.md).

One screen; the stepper updates in place for all four states. Brass fill = done, brass ring = active, hollow = pending. Cancel is only enabled before “Preparing” (shown disabled here).
